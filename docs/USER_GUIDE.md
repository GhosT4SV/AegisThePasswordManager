# Руководство пользователя Aegis

## Первый запуск

1. Распакуйте всю папку `dist\\Aegis` в отдельный каталог, доступный для записи.
2. Запустите `Aegis.exe`.
3. Введите имя аккаунта и мастер-пароль от 12 символов, затем выберите
   `Register`. Запомните пароль: сброса через почту или восстановления без
   резервной копии нет.
4. Для входа введите те же имя и пароль и выберите `Login`.

Каждый аккаунт создаёт отдельный файл в `vaults`. Используйте разные мастер-
пароли для разных аккаунтов. Не запускайте несколько копий из одной папки.

## Работа с записями

- На вкладке `Vault` заполните Service, Login и Password; остальные поля
  (Website URL, Category, Notes) необязательны. Нажмите `Add`.
- Чтобы изменить запись, выберите её, нажмите `Edit selected`, поправьте поля и
  нажмите `Save changes`.
- Поиск проверяет сервис, логин, URL, категорию и заметку.
- Значок глаза временно показывает пароль. `Copy` копирует пароль в системный
  буфер обмена; Aegis очищает его по таймеру, если другое приложение не заменило
  содержимое раньше.
- Генератор использует системный криптографический источник случайности. Перед
  сохранением проверьте выбранные наборы символов и длину.

## Блокировка и мастер-пароль

В `Settings` можно настроить автоблокировку и параметры сеанса. В `Account`
можно сменить мастер-пароль: операция сохраняет только хранилище текущего
аккаунта. Старые резервные копии после смены продолжают открываться прежним
паролем. Не включайте self-destruct passphrase, если не понимаете, что её ввод
удалит активный файл выбранного аккаунта; сохранённые копии и legacy-файл она не
удаляет.

## Резервирование и перенос

- Создайте encrypted backup и храните его отдельно от приложения. Для
  восстановления нужен пароль, которым копия была сделана.
- `Restore backup` заменяет текущий vault. Сначала убедитесь, что выбрана верная
  копия; операция необратима для незарезервированных изменений.
- CSV импорт/экспорт содержит открытые пароли. Экспортируйте только после
  предупреждения, храните файл в защищённом месте и удалите его после работы.
- Старая общая база `Aegis.db` переносится по одному аккаунту при успешном
  входе. Исходник сохраняется до окончания миграции всех профилей. Создайте
  отдельную резервную копию и удалите/архивируйте legacy-файл вручную только
  после сверки каждого аккаунта.

## Проверка утечек

HIBP отключён по умолчанию. В настройках его можно включить для проверки при
входе; ручная проверка отдельной записи запускается кнопкой `Check selected`.
Сервис получает первые пять символов SHA-1-хэша и видит IP-адрес и время
запроса. Полный пароль не отправляется. Отключите функцию, если не хотите
сетевого обращения.

## Если что-то пошло не так

- `Could not open vault`: проверьте имя аккаунта, пароль, права записи и
  целостность файла. Повреждённый файл не удаляйте; попробуйте копию резервной
  копии.
- `Aegis is already running`: закройте уже запущенный экземпляр и повторите.
- Не удаляйте `vaults`, `Aegis.db`, резервные копии или файлы состояния, пока не
  разобрались с их назначением.
- Если мастер-пароль потерян и нет доступной резервной копии, восстановление
  данных не предусмотрено.
