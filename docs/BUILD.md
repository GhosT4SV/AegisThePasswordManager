# Сборка и фиксация релиза Aegis

## Воспроизведение

Проверенная среда: Windows x64, Python 3.11.0. Зафиксированные версии
пакетов находятся в `requirements-lock.txt`.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
python -B -m unittest discover -s tests -v
python -m PyInstaller --clean --noconfirm Aegis.spec
```

Результат `onedir` — папка `dist\Aegis`; для переноса скопировать всю папку,
а запускать `Aegis.exe`. Каталог должен быть доступен для записи. Для проверки
чистой установки запускать копию в отдельном пустом каталоге, не каталог,
содержащий рабочие данные.

## Известное ограничение текущего билда

Текущий EXE был собран на Python 3.11.0. На дату записи это устаревший patch-
релиз runtime, поэтому данный EXE следует считать учебным прототипом и не
использовать для реальных паролей. Для release candidate нужно пересобрать его
на исправленной версии Python, затем повторить тесты, сборку и GUI-приёмку.
PyInstaller 6.22.3 поддерживает Python 3.15, но обновлённый runtime пока не
установлен в рабочей среде; текущий EXE не подменялся неподтверждённой сборкой.

## Зафиксированный билд

- Дата сборки: 2026-10-26.
- Python: 3.11.0 x64.
- PyInstaller: 6.22.3.
- Команда: `python -m PyInstaller --clean --noconfirm Aegis.spec`.
- Автоматические проверки: 13 unit-тестов проходят.
- Ручной запуск GUI и полный сценарий EXE: `NOT RUN`; это не считается
  подтверждением работоспособности интерфейса.
- SHA-256 `dist\\Aegis\\Aegis.exe`:
  `1caf9ad011fa0d59c4e45c9f3313de326ae73262f7432f73bc3eb3b67e284936`.

Хэш исполняемого файла следует записывать непосредственно после сборки:

```powershell
Get-FileHash dist\Aegis\Aegis.exe -Algorithm SHA256
```

После копирования билда в дипломный каталог сравнить SHA-256 обоих EXE и
сохранить результат рядом с итоговым протоколом испытаний. Не включать в
протокол, репозиторий или архив с исходниками реальные базы, ключи и журналы.
