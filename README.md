Локальный настольный менеджер паролей на Python и CustomTkinter.

## Запуск

Требуется Windows и Python 3.11 или новее. Для повседневного использования
ставьте актуальный исправленный patch-релиз поддерживаемой ветки Python.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
python main.py
```

`Aegis.pyw` можно запускать двойным щелчком после установки зависимостей.
Приложению нужна папка с исходниками, доступная для записи: рядом с кодом
хранятся зашифрованная база, настройки темы и файлы защиты от перебора.

## Portable-сборка Windows

Из корня проекта выполните:

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean Aegis.spec
```

`requirements-lock.txt` фиксирует полный набор версий среды, включая сборщик;
для воспроизведения проверенного билда используйте именно его.

Запускайте `dist\Aegis\Aegis.exe` из папки, доступной для записи. Сборка
использует формат `onedir`: база и локальные настройки хранятся рядом с EXE.
Не перемещайте и не публикуйте sidecar-файлы из этой папки; `Aegis.db`
зашифрован, а журналы и параметры блокировки относятся к пользователю.

## Возможности

- Отдельный JSON-файл хранилища для каждого аккаунта, зашифрованный AES-256-GCM; ключ получается из мастер-пароля через Argon2id.
- Записи с сервисом, логином, паролем, URL, категорией и заметкой; поиск и редактирование.
- Генератор на `secrets`, который включает по одному символу из каждого выбранного набора.
- Таймер очистки системного буфера, блокировка после бездействия, настраиваемый счётчик ошибок входа.
- Проверка паролей через Pwned Passwords API по явному включению. Для запроса передаётся префикс SHA-1, а сервис видит IP-адрес и время запроса; полный пароль не отправляется.
- Резервная копия — копия уже зашифрованного файла базы. Восстановление требует тот же мастер-пароль, которым эта копия была сохранена.
- Импорт и экспорт CSV. Экспорт CSV содержит открытые пароли; приложение показывает предупреждение перед записью.

## Где лежат данные

Новые аккаунты хранятся в `vaults/` в отдельных зашифрованных файлах с именами,
полученными из хэша имени аккаунта. Старая общая база `Aegis.db` переносится
по одному аккаунту при первом успешном входе; исходник сохраняется, чтобы можно
было перенести остальные аккаунты. После проверки переноса всех аккаунтов
сделайте зашифрованную резервную копию и вручную переместите старый `Aegis.db`
в архив или удалите его. Пока он лежит рядом с программой, в нём остаётся старая
общая копия данных. После миграции каждый аккаунт может сменить пароль независимо.

`Aegis_secret.key` и `Aegis_state.bin`
относятся к локальному счётчику неудачных входов; журналы не содержат пароли,
но могут раскрывать время запуска и события входа. Не публикуйте эти файлы.
Храните резервные копии отдельно и проверяйте их восстановлением на тестовых данных.

CSV — незашифрованный формат. Удалите экспорт после использования и храните его
в защищённом месте. Удаление файла на SSD или в синхронизируемой папке не
гарантирует физическое стирание всех копий.

## Ограничения модели безопасности

Aegis защищает файл базы от чтения без мастер-пароля, но не защищает открытый
сеанс от вредоносного ПО, кейлоггера, снимка памяти или доступа к разблокированному
пользовательскому профилю Windows. Буфер обмена системный; приложение очищает его
по таймеру, если содержимое не было заменено другим приложением.

Старая общая база не обеспечивает изоляцию аккаунтов, пока не перенесены все её
профили и не убрана исходная копия. Имена файлов новых хранилищ не содержат
имена пользователей, но файловая система и права Windows остаются частью модели
защиты.

Проверки виртуальной машины и отладчика — эвристические сигналы, они могут давать
ложные срабатывания и не являются границей безопасности. Локальный файл хэшей,
если он создан разработчиком, не подписан внешним ключом и не доказывает подлинность
программы. Самоуничтожение удаляет активный файл базы; отдельно сохранённые копии
остаются восстановимыми.

Смена мастер-пароля требует минимум 12 символов и перешифровывает текущую базу.
Старые резервные копии остаются защищены прежним паролем.
